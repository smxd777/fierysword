# fierysword

Мод для Minecraft, который добавляет «Огненный меч» — боевой инструмент с высокой прочностью, поджигающий врагов при ударе.
Что добавляет мод
Предмет Огненный меч (fiery-sword:fiery_sword):

наносит урон в ближнем бою;
при ударе поджигает цель на 3 секунды;
по ПКМ выводит сообщение «Огненный меч пылает в руке!»;
доступен во вкладке «Бой».

Совместимость

Minecraft: 1.21.1
Fabric Loader: 0.20.1
Fabric API: 0.116.17+1.21.1
Java: 21

Другие версии не проверялись.
Установка

Установите Minecraft и Fabric Loader 0.20.1 для 1.21.1.
В mods положите Fabric API и fiery-sword-1.0.0.jar (JAR из build/libs без -sources).
Запустите игру. Меч должен быть во вкладке «Бой» и по команде /give @s fiery-sword:fiery_sword.

Использование

Получение: вкладка «Бой» или /give @s fiery-sword:fiery_sword
Рецепт: 4 стержня ифрита + палка
Свойства: прочность 3000, стек 1, урон ≈ 10
ПКМ — сообщение; ЛКМ по мобу — поджог на 3 сек

Сборка
text.\gradlew.bat clean build
JAR: build/libs без -sources. Нужен JDK 21.
Ограничения
Нет конфига огня, только 1.21.1, сервер не проверялся, нужен Loader ≥ 0.20.1.
